# FINAL REQUIREMENT MATRIX — v1.1.3

তারিখ: ২০২৬-১১-০৪ · ভিত্তি: `docs/07-requirements-traceability.md`-এর ৮৪টি রিকোয়্যারমেন্ট (A1–J)
এবং এই অডিটে যোগ হওয়া পেশাদার POS-এর জন্য অপরিহার্য নতুন আইটেম।

স্টেটাস: `PASS` (বাস্তবায়িত + স্বয়ংক্রিয় যাচাই) · `PARTIAL` (কাজ করে তবে সীমা আছে) ·
`MISSING` (নেই) · `BLOCKED` (পরিবেশের কারণে যাচাই হয়নি) · `NOT APPLICABLE`।

> নিয়ম: শুধু বাটন/টেবিল/স্ক্রিন থাকলেই PASS নয় — **পুরো ওয়ার্কফ্লো** (UI → IPC → সার্ভিস → DB →
> ফল → UI) এবং তার স্বয়ংক্রিয় প্রমাণ থাকতে হবে। যে আইটেমে প্রমাণ নেই সেটি PASS নয়।

## ১. মূল ৮৪টি রিকোয়্যারমেন্ট (গোষ্ঠীভিত্তিক অবস্থা)

`docs/07-requirements-traceability.md`-এ প্রতিটি আইডির (A1–J5) বিপরীতে বাস্তবায়ন ফাইল ও
যাচাইয়ের পদ্ধতি লেখা আছে; সেটি v1.0.x-এ শেষবার গণনা করা (✅ ৭৫ · 🟡 ৯ · ⛔ ০)। এই অডিটে
আমি প্রতিটি আইডি কোড ও টেস্টের সঙ্গে মিলিয়ে দেখেছি, কিন্তু **নতুন করে সংখ্যা বানাইনি** —
নিচে যা আছে তা এই সেশনে প্রকৃতপক্ষে যা যাচাই হয়েছে তার সারাংশ।

| গোষ্ঠী | অবস্থা | এই অডিটে যা দেখা হলো |
|---|---|---|
| A — প্ল্যাটফর্ম ও ডেলিভারেবল | PASS (A8 BLOCKED) | দুই আলাদা এক্সিকিউটেবল, অফলাইন, বাংলা UI; ইনস্টলার আপগ্রেড Windows-এ |
| B — ডেটা ও আর্থিক নির্ভুলতা | PASS | পূর্ণসংখ্যা poisa (`domain/money.ts`), `roundDiv`, WAC; কোনো ফ্লোট টাকা নেই |
| C — প্রোডাক্ট ও স্টক | PASS (লেবেল প্রিন্ট BLOCKED) | স্টক মুভমেন্ট সবই `applyMovement`-এ, লেনদেনে; সিরিয়াল এখন POS থেকে |
| D — POS ও বিক্রয় | PASS (D7/D8 হার্ডওয়্যার BLOCKED) | হোল্ড/রিসিউম, স্প্লিট পেমেন্ট, কুপন/গিফট/লয়্যালটি, বাতিলে সম্পূর্ণ রিভার্সাল |
| E — পারচেজ ও সাপ্লায়ার | PASS | আংশিক রিসিভ idempotent (`invariants.test.ts`), সাপ্লায়ার-বিহীন বাকি নিষিদ্ধ |
| F — কাস্টমার, বাকি ও CRM | PASS | ক্রেডিট লিমিট, লয়্যালটি লেজার, গিফট কার্ড, কোটা |
| G — রিটার্ন ও এক্সচেঞ্জ | PASS (v1.1.3-এ শক্তিশালী) | `appliedToDue`, কুপন ফেরত, সিরিয়াল ফেরত, এক্সচেঞ্জ নিট |
| H — হিসাব (ডাবল-এন্ট্রি) | PASS | ট্রায়াল/ব্যালেন্স শিট/reconcile প্রতিটি ইনভেরিয়েন্ট টেস্টে |
| I — রিপোর্ট ও প্রিন্ট | PASS (প্রিন্টার BLOCKED) | ৫৪টি রিপোর্ট, রিপোর্ট ↔ টেবিল মিলকরণ টেস্ট |
| J — সিস্টেম, নিরাপত্তা ও রিলিজ | PASS (v1.1.3-এ আরও কঠিন) | sender যাচাই, কী ট্রাস্ট, এনক্রিপ্টেড LAN, গেট সমান |

সংখ্যায় দাবি না করে বলা ভালো: **যা স্বয়ংক্রিয়ভাবে প্রমাণিত তা ২৮২টি টেস্টে ঢাকা**; যা ঢাকা নেই
(হার্ডওয়্যার, Windows ইনস্টলার, দুই-পিসি LAN) সেগুলো BLOCKED হিসেবে §৩-এ লেখা।
