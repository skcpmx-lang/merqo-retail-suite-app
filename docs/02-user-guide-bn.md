# ব্যবহার নির্দেশিকা (দোকানদারের জন্য)

এই নির্দেশিকাটি সাউদা রিটেইল স্যুট ব্যবহার করে দৈনন্দিন কাজ কীভাবে করবেন তা ধাপে ধাপে দেখায়।

---

## ১. প্রথমবার চালু করা

1. **ইনস্টলার চালান** — `Sauda-Retail-Suite-Setup-x.y.z.exe`। Windows স্মার্টস্ক্রিনে “More info → Run anyway” লাগতে পারে।
2. **লাইসেন্স অ্যাক্টিভেশন** — যে ফাইলটি সেলার পাঠিয়েছেন (`.sauda`) সেটি “লাইসেন্স ফাইল” ট্যাব থেকে লোড করুন,
   অথবা লাইসেন্স কী পেস্ট করুন।
   - নিজের কম্পিউটারের ডিভাইস আইডি পাঠাতে হলে **“ডিভাইস রিকোয়েস্ট ফাইল সংরক্ষণ”** চাপুন এবং সেই ফাইলটি সেলারকে পাঠান।
3. **সেটআপ উইজার্ড** — দোকানের নাম, ঠিকানা, মোবাইল, অ্যাডমিনের নাম, ইউজারনেম ও পাসওয়ার্ড দিন; রিসিটের প্রস্থ
   (৫৮ বা ৮০ মিমি) বেছে নিন।
4. **লগইন** — ইউজারনেম ও পাসওয়ার্ড দিয়ে ঢুকুন।

> প্রথমবারেই সেটিংস → প্রিন্টার থেকে **“টেস্ট প্রিন্ট”** চালিয়ে দেখুন প্রিন্টার ঠিক আছে কিনা।

## ২. প্রোডাক্ট যোগ করা

1. বাম মেনু → **প্রোডাক্ট** → **নতুন প্রোডাক্ট**।
2. নাম, ক্যাটাগরি, ইউনিট (পিস/কেজি/লিটার) দিন।
3. **মূল্য** ট্যাব: ক্রয়মূল্য ও বিক্রয়মূল্য (টাকায়) দিন — মার্জিন নিজেই দেখাবে।
4. **স্টক** ট্যাব: হাতে থাকা পরিমাণ (ওপেনিং স্টক) ও সর্বনিম্ন স্টক (অ্যালার্ট) দিন।
5. **বারকোড ও অন্যান্য** ট্যাব: বারকোড, ছবি, ব্যাচ/মেয়াদ ট্র্যাকিং।
6. বেশি প্রোডাক্ট থাকলে **CSV ইমপোর্ট** ব্যবহার করুন — আগে “টেমপ্লেট” নামিয়ে নিন।

## ৩. বিক্রয় (POS)

1. বাম মেনু → **বিক্রয় (POS)** (শর্টকাট `F2`)।
2. প্রোডাক্টের টাইলে ক্লিক করুন, অথবা উপরের বক্সে নাম/এসকেইউ লিখুন, অথবা **বারকোড স্ক্যান** বক্সে স্ক্যান করুন।
3. ডান দিকের কার্টে পরিমাণ `+`/`−` দিয়ে বদলান, ইউনিট বদলাতে চাইলে ছোট ড্রপডাউন ব্যবহার করুন।
4. কাস্টমার বেছে নিন (বাকি বিক্রয়ের জন্য অবশ্যই)।
5. **পেমেন্ট (F8)** → প্রাপ্ত টাকা লিখুন, মাধ্যম বেছে নিন, প্রয়োজনে রেফারেন্স (bKash TrxID) দিন।
6. **বিক্রয় সম্পন্ন করুন** — রিসিট প্রিভিউ আসবে; প্রিন্ট করুন বা নতুন বিক্রয় শুরু করুন।

টিপস:
- ডিসকাউন্ট বা দাম বদলানোর অনুমতি না থাকলে বোতাম দেখাবে না।
- ভুল হলে ইনভয়েস বাতিল করুন (**সেলস ও ইনভয়েস** → ইনভয়েস → বিস্তারিত → বাতিল, অ্যাডমিন ও কারণ প্রয়োজন)।

## ৪. পারচেজ (মাল কেনা)

1. **পারচেজ** → **নতুন পারচেজ**।
2. সাপ্লায়ার বেছে নিন, প্রোডাক্ট সার্চ করে যোগ করুন, পরিমাণ ও ক্রয়মূল্য দিন।
3. পরিবহন/অন্যান্য খরচ থাকলে লিখুন — এগুলো পণ্যের দামের সাথে বণ্টিত হয়ে গড় ক্রয়মূল্য ঠিক রাখবে।
4. “এখন পরিশোধ” খালি রাখলে পুরো টাকা পাওনা হিসাবে সাপ্লায়ারের খাতে যাবে।
5. সংরক্ষণ করুন — স্টক নিজে থেকেই বাড়বে।

## ৫. কাস্টমারের বাকি আদায়

**কাস্টমার ও বাকি** → কাস্টমারের পাশে **আদায়** → টাকা ও মাধ্যম দিন।
সম্পূর্ণ খাতা দেখতে ফাইল আইকনে চাপুন (ডেবিট/ক্রেডিট/ব্যালেন্স সহ স্টেটমেন্ট)।

## ৬. রিটার্ন ও রিফান্ড

- কাস্টমার পণ্য ফেরত দিলে: **রিটার্ন ও রিফান্ড** → **সেলস রিটার্ন** → ইনভয়েস নম্বর খুঁজে নিন →
  পরিমাণ ও অবস্থা (ভালো/নষ্ট/মেয়াদোত্তীর্ণ) দিন → রিফান্ডের টাকা নিশ্চিত করুন।
- “ভালো অবস্থার পণ্য আবার স্টকে ফিরবে” চালু থাকলে স্টক বেড়ে যাবে; নষ্ট হলে স্টকে ফিরবে না।
- সাপ্লায়ারকে মাল ফেরত দিলে **পারচেজ রিটার্ন**।

## ৭. রিপোর্ট ও এক্সপোর্ট

১. **রিপোর্ট** (F9) → বাম দিকের তালিকা থেকে রিপোর্ট বেছে নিন।
২. তারিখের প্রিসেট (আজ / ৭ দিন / এই মাস / গত মাস / বছর) বা কাস্টম তারিখ দিন।
৩. উপরে ডান দিকের **CSV / Excel / PDF** বোতামে ফাইল সংরক্ষণ করুন।

দরকারি রিপোর্ট:
| প্রশ্ন | রিপোর্ট |
|---|---|
| আজ কত বিক্রি হলো? | দৈনিক সেলস |
| লাভ কত? | প্রফিট ও লস |
| কে কত বাকি? | কাস্টমার বাকি |
| সাপ্লায়ারকে কত দিতে হবে? | সাপ্লায়ার পাওনাবিলি |
| স্টকের মূল্য কত? | স্টক ভ্যালুয়েশন |
| কোন পণ্য কম চলছে? | স্লো মুভিং |

## ৮. ক্যাশ রেজিস্টার

প্রতিদিন শুরুতে **ক্যাশ রেজিস্টার → নতুন সেশন খুলুন** (ড্রয়ারে থাকা টাকা লিখুন)।
দিনের শেষে **সেশন বন্ধ** → গণনা করা টাকা লিখুন — পার্থক্য অডিটে সংরক্ষিত হবে।

## ৯. ব্যাকআপ (খুব গুরুত্বপূর্ণ)

- **ব্যাকআপ ও রিস্টোর → এখনই ব্যাকআপ নিন**। ফাইলটি (`.saudabak`) পেনড্রাইভ বা অন্য কম্পিউটারে রাখুন।
- সেটিংস থেকে **স্বয়ংক্রিয় ব্যাকআপ** চালু রাখুন (প্রতিদিন/সাপ্তাহিক)।
- নতুন কম্পিউটারে যেতে হলে: ইনস্টল → লাইসেন্স (নতুন ডিভাইস রিকোয়েস্ট) → রিস্টোর।

## ১০. ইউজার তৈরি (ক্যাশিয়ার)

সেটিংস → **ইউজার** → **নতুন ইউজার** → রোল “ক্যাশিয়ার” → প্রয়োজনীয় অনুমতি টিক দিন
(বিক্রয়, প্রোডাক্ট দেখা, কাস্টমার, রিপোর্ট)। ক্যাশিয়ারকে ডিলিট, সেটিংস বা ব্যাকআপের অনুমতি না দেওয়াই ভালো।

| `F4` | পারচেজ |
| `F5` | কাস্টমার |

| `Esc` | মডাল বন্ধ |

## সমস্যা হলে

1. **প্রিন্ট হচ্ছে না** — সেটিংস → প্রিন্টার → প্রিন্টার নির্বাচন → টেস্ট প্রিন্ট। Windows-এ প্রিন্টার “Offline” নয় কিনা দেখুন।
2. **বাংলা অক্ষর ভাঙা** — Windows-এ “Nirmala UI” ফন্ট থাকা দরকার (Windows 10/11-এ ডিফল্ট)।
3. **লাইসেন্স মেয়াদ শেষ/ডিভাইস বদল** — সেলারের সাথে যোগাযোগ করুন।
4. **ডাটাবেজ সন্দেহ হলে** — সেটিংস → ডায়াগনস্টিক → “ডাটাবেজ যাচাই”।
5. কিছুই কাজ না করলে অ্যাপ বন্ধ করে আবার চালু করুন; তথ্য কখনো মুছে যায় না।
