# V1.1.5 — module inventory

Complete inventory of the repository as audited for v1.1.5. Every module listed here is in scope for
the audit; the "audit status" column is filled in as each module is examined (see
`V1.1.5_AUDIT_REPORT.md` for findings and `V1.1.5_ISSUE_REGISTER.md` for the defect list).

Legend for audit status: `NOT STARTED` · `AUDITED` · `AUDITED + FIXED` · `BLOCKED (needs Windows VM)`.

## 1. Workspace layout

```
package.json            workspace root: scripts, dev dependencies, engines
tsconfig.base.json      shared TS settings
vitest.config.ts        test include patterns, CI reporters, DB leak guard (setupFiles)
test-setup/             database-leak-guard.ts, temp-resources.ts (test infrastructure)
build/                  icons (ico/png) used by electron-builder
packages/core/          @sauda/core — domain, database, services, licensing, LAN, printing
packages/app/           sauda-pos — Electron main/preload/renderer (Main App)
packages/license-generator/  sauda-license-generator — Electron main/preload/renderer (internal tool)
scripts/                build, verify, packaging, release tooling + scripts/tests
docs/                   83 markdown documents (architecture, guides, audits, release records)
.github/workflows/      ci.yml (Linux + Windows gates), release.yml (build → verify → draft → publish)
```
