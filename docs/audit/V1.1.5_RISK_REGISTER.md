# V1.1.5 — risk register

Living document. Each risk has an ID, a severity, the evidence that put it on the list, the planned
disposition, and its current status. **A risk is only closed when the evidence exists** — a passing
gate elsewhere does not close a risk.

Status values: `OPEN` · `MITIGATING` · `CLOSED (evidence)` · `ACCEPTED LIMITATION` · `BLOCKED (needs Windows VM)`.

## E. How this register is used

1. Every issue found in `V1.1.5_AUDIT_REPORT.md` gets an ID here (or references the risk that produced it).
2. A risk may only move to `CLOSED` with a test name, a run link, or a command + output recorded in the
   release verification document.
3. Anything left open at release time is carried into `V1.1.5_KNOWN_LIMITATIONS.md` **and** into the
   release notes, with its user-visible impact.
