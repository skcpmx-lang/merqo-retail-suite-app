# FINAL LICENSE AUDIT — v1.1.3

তারিখ: ২০২৬-১১-০৪ · দুই অ্যাপ: মূল POS (`packages/app`) ও লাইসেন্স জেনারেটর (`packages/license-generator`)

---

## ১. ক্রিপ্টোগ্রাফি

| বিষয় | মান |
|---|---|
| অ্যালগরিদম | **Ed25519** (Node `crypto`) |
| সাইন করার ইনপুট | `canonicalJson({ payload, signature? })` বাদ দিয়ে শুধু `payload`-এর ক্যানোনিক্যাল JSON |
| কী বিন্যাস | SPKI DER → base64 (পাবলিক), PKCS#8 PEM/base64 (প্রাইভেট) |
| ডিভাইস বাইন্ডিং | SHA-256 ফিঙ্গারপ্রিন্ট উপাদান (machineId/CPU/প্ল্যাটফর্ম/হোস্ট, নরমালাইজড) |
| লাইসেন্স ফাইল | `{ v, payload, signature }` JSON — `.saudalic` |

v1.1.3-এ **যা বদলেছে:** পাবলিক কী এখন কম্পাইল-করা ধ্রুবক; `SAUDA_LICENSE_PUBLIC_KEY` এনভায়রনমেন্ট
ভেরিয়েবল আর পড়া হয় না (আগে যে কেউ নিজের চাবি দিয়ে লাইসেন্স বানাতে পারত)।

## ২. যাচাইয়ের ক্রম (`verify.ts`)

1. **স্ট্রাকচার** — ফাইল JSON কিনা, `payload` ও `signature` আছে কিনা।
2. **সিগনেচার** — Ed25519 ভেরিফাই; ব্যর্থ হলে `signature_invalid`, কিছুই আনলক হয় না।
3. **স্কিমা** — `v` সমর্থিত, `license_id`, `org`, `edition`, `fingerprint`, `features[]`, `issued_at`।
4. **মেয়াদ** — `expires_at`-এর শেষ দিন পর্যন্ত (লোকাল দিনক্ষণ, দোকানের ঘড়ি)।
5. **ডিভাইস** — ফিঙ্গারপ্রিন্ট মিললে সক্রিয়; না মিললে `device_mismatch` (আন্ডারলাইন/নেটওয়ার্ক পরিবর্তনে
   নরমালাইজেশন টলারেন্স আছে)।
6. **ফিচার** — `features[]` তালিকা; `LICENSE_EXEMPT_PREFIXES = ['license.', 'setup.', 'auth.', 'app.', 'meta.']`
   সবসময় খোলা, বাকি সব রুট ফিচার-গেটেড।

ফলাফল `ActivationState`: `activated`, `reason`, `message`, `license`, `device`, `days_left`।

## ৩. জেনারেটর (সাইনিং অরথরিটি)

| বিষয় | ফল |
|---|---|
| প্রাইভেট কী কোথায় | অপারেটরের বেছে নেওয়া PEM/JSON ফাইল থেকে মেইন প্রসেসে লোড; মেমরিতে (কেবল বেস৬৪) থাকে, রেন্ডারারে যায় না |
| কী ডিস্কে লেখা হয়? | জেনারেটর নিজে প্রাইভেট কী লেখে না; কনফিগে শুধু `keyPath` সংরক্ষিত হয় |
| কী রেন্ডারারে ফেরত যায়? | না — UI শুধু `keyId` ও `publicKeyB64` দেখে (ফিঙ্গারপ্রিন্ট হিসেবে) |
| প্যাকেজড বিল্ডে dev URL | এখন সম্পূর্ণ উপেক্ষিত; loopback-এর বাইরে কোনো URL নয় |
| IPC sender যাচাই | `isTrustedSender(event)` — v1.1.3-এ যোগ |
| navigation / নতুন উইন্ডো | ব্লক (`will-navigate`, `setWindowOpenHandler`, `will-attach-webview`) |
| `sandbox` | `true` (v1.1.3) |
| DevTools | শুধু unpackaged |
| অডিট লগ | প্রতিটি সাইন/কী-অপারেশন ফাইলে অ্যাপেন্ড (কী নিজে নয়, শুধু কী-ফিঙ্গারপ্রিন্ট) |

## ৪. রিভোকেশন, ট্রায়াল ও এজ

| বিষয় | স্টেটাস | ব্যাখ্যা |
|---|---|---|
| অফলাইন সাইন-ভিত্তিক মেয়াদ | PASS | `expires_at` + `days_left` |
| নবায়ন (`renew`) | PASS | নতুন সাইনে `license_id` একই রেখে মেয়াদ বাড়ে |
| রিভোকেশন | PARTIAL | অফলাইনে কেন্দ্রীয় রিভোকেশন সম্ভব নয়; শুধু সংক্ষিপ্ত মেয়াদ + নবায়ন। `docs/09`-এ নথিভুক্ত |
| ট্রায়াল | PASS | ফিচার-ফ্ল্যাগে সময়সীমা; স্কিমার `edition` দিয়ে নিয়ন্ত্রিত |
| ক্লক-রোলব্যাক | PARTIAL | মেয়াদ লোকাল ঘড়ি পড়ে; অডিট-লগে সময়-ব্যতিক্রম ধরা পড়ে, কঠোর প্রতিরোধ নেই |
| কী রোটেশন | PARTIAL | নতুন পাবলিক কী কম্পাইল করে বিতরণ করতে হয়; পুরোনো লাইসেন্স নতুন কী দিয়ে যাচাই হয় না (ইচ্ছাকৃত, নথিভুক্ত) |

## ৫. স্টোরেজ

- `licence` টেবিলে (এনক্রিপ্টেড নয়) + `outcome` মেটাডেটা; ফিঙ্গারপ্রিন্টও সেখানে।
- কী-মেটেরিয়াল কোনো লগ, ডায়াগনস্টিক, এক্সপোর্ট বা ব্যাকআপে যায় না — `diagnostics` এক্সপোর্টে
  শুধু `license_id`, `edition`, `expires_at`, `days_left`।
- `verify.mjs` এখন ট্র্যাক করা সব টেক্সটে PEM প্রাইভেট কী ও env-override প্যাটার্ন খোঁজে;
  `scripts/verify-installer.mjs` CI-তে ইনস্টলারের ভেতরে কী-ফাইল খোঁজে।
