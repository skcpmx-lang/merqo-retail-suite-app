# লাইসেন্সিং

সম্পূর্ণ **অফলাইন**, **হার্ডওয়্যার-বাউন্ড**, **Ed25519 স্বাক্ষরিত** লাইসেন্স। অ্যাপ কখনো ইন্টারনেটে
যায় না; শুধু গণিত দিয়ে স্বাক্ষর যাচাই করে।

## ১. উপাদান

| অংশ | ফাইল | কী |
|---|---|---|
| কী তৈরি | `scripts/generate-signing-keys.mjs` | Ed25519 keypair → `secrets/` (git-ignored) |
| পাবলিক কী | `packages/core/src/licensing/publicKey.ts` | অ্যাপে এমবেড করা SPKI base64 + KEY_ID |
| ইস্যু | `packages/core/src/licensing/issue.ts` | পেলোড তৈরি + স্বাক্ষর |
| যাচাই | `packages/core/src/licensing/verify.ts` | স্কিমা, স্বাক্ষর, মেয়াদ, ডিভাইস ম্যাচ |
| ফিঙ্গারপ্রিন্ট | `packages/core/src/licensing/fingerprint.ts` | ৪টি হার্ডওয়্যার উপাদানের ওয়েটেড হ্যাশ |
| সংরক্ষণ | `packages/core/src/licensing/store.ts` | `activations` টেবিল, ক্লক-রোলব্যাক গার্ড |
| তৈরি করার টুল | `packages/license-generator` | আলাদা Windows EXE (MERQO-র জন্য) |

## ২. ফরম্যাট

### লাইসেন্স কী

```
SAUDA1.<base64url(payload JSON)>.<base64url(Ed25519 signature)>
```

`payload` (সংস্করণ ১):

```json
{
  "v": 1,
  "license_id": "SAUDA-XXXX-XXXX",
  "org": "করিম জেনারেল স্টোর",
  "owner": "মোঃ করিম",
  "edition": "pro",
  "issued_at": "2026-01-01T00:00:00.000Z",
  "expires_at": null,
  "max_devices": 1,
  "fingerprint": "<sha256(components)।slice(0,40)>",
  "device_components": [{ "key": "board", "hash": "…", "weight": 45 }],
  "fingerprint_version": 1,
  "features": ["pos", "inventory", "…"],
  "generator": "Sauda License Generator 1.0.0"
}
```

### লাইসেন্স ফাইল (`.sauda`)

```json
{
  "format": "sauda-license",
  "v": 1,
  "key": "SAUDA1.…",
  "payload": { … },
  "device_fingerprint": "…",
  "issued_by": "Sauda License Generator",
  "issued_at": "2026-01-01T00:00:00.000Z"
}
```

### ডিভাইস রিকোয়েস্ট (`.sauda-device`)

গ্রাহকের অ্যাক্টিভেশন স্ক্রিন থেকে তৈরি হয়। এতে শুধু **হ্যাশ** থাকে:

```json
{
  "kind": "sauda-device-request",
  "v": 1,
  "fingerprint": "…",
  "components": [{ "key": "board", "hash": "…", "weight": 45 }, …],
  "platform": "win32",
  "app_version": "1.0.0",
  "business_name": "করিম জেনারেল স্টোর",
  "created_at": "…"
}
```

## ৩. ফিঙ্গারপ্রিন্ট ও রিবাইন্ডিং

| উপাদান | ওয়েট | কী |
|---|---:|---|
| `board` | ৪৫ | মাদারবোর্ড সিরিয়াল |
| `disk` | ৩০ | সিস্টেম ডিস্ক সিরিয়াল |
| `cpu` | ১৫ | প্রসেসরের আইডি |
| `bios` | ১০ | BIOS সিরিয়াল |

- প্রতিটি উপাদানের মান **হ্যাশ** করে রাখা হয় (কাঁচা সিরিয়াল কোথাও যায় না)।
- অ্যাপ চালু হওয়ার সময় বর্তমান উপাদানের সাথে তুলনা হয়; **৬০% ওয়েট** মিললেই লাইসেন্স বৈধ।
  ফলে RAM/GPU/নেটওয়ার্ক কার্ড বদলালে সমস্যা হয় না।
- স্টোরেজ বা মাদারবোর্ড বদলালে (বড় ওয়েট) আর মিলবে না — তখন MERQO নতুন ডিভাইস রিকোয়েস্ট ফাইল নিয়ে
  **নতুন লাইসেন্স ইস্যু** করবে। এটিই “নিয়ন্ত্রিত রিবাইন্ডিং”: প্রতিটি রিবাইন্ডের অনুরোধ ম্যানুয়ালি যাচাই হয়।
- অল-জিরো বা প্লেসহোল্ডার আইডি প্রত্যাখ্যাত হয় (ভিএম-এ যাতে ব্ল্যাঙ্ক ফিঙ্গারপ্রিন্ট দিয়ে চালানো না যায়)।

## ৪. ক্লক-রোলব্যাক সুরক্ষা

মেয়াদযুক্ত লাইসেন্সে অ্যাপ সবচেয়ে বড় দেখা সময় (`meta.license.max_seen`) মনে রাখে। সিস্টেমের ঘড়ি
পিছিয়ে দিলে যাচাই `clock_tamper` দিয়ে ব্যর্থ হয়।

## ৫. কী ব্যবস্থাপনা (MERQO-র জন্য)

```bash
node scripts/generate-signing-keys.mjs           # নতুন কী জোড়া → secrets/
# পাবলিক কী + KEY_ID কপি করে publicKey.ts-এ বসাতে হবে, তারপর দুই অ্যাপ রিবিল্ড
```

নিয়ম:
1. প্রাইভেট কী কখনো রিপোজিটরিতে, ইনস্টলারে বা CI আর্টিফ্যাক্টে যাবে না (প্যাকেজিং স্ক্রিপ্ট এটি যাচাই করে)।
2. প্রাইভেট কী দুই জায়গায় অফলাইন ব্যাকআপ রাখুন (এনক্রিপ্টেড ড্রাইভ/কাগজে)।
3. কী হারালে পুরোনো সব লাইসেন্স যাচাইয়ে ব্যর্থ হবে — তাই বছরে অন্তত একবার কী নষ্ট হলে কী করবেন তা রিহার্সাল করুন।
4. কী বদলাতে হলে নতুন পাবলিক কী দিয়ে অ্যাপ রিলিজ → সব গ্রাহককে নতুন লাইসেন্স ইস্যু।

## ৬. লাইসেন্স তৈরি (ধাপে ধাপে)

1. `Sauda-License-Generator-*.exe` চালু করুন।
2. **প্রাইভেট কী লোড করুন** → `ed25519-private-b64.txt` বেছে নিন। কী প্রস্তুত হলে পিল সবুজ হবে ও KEY_ID দেখাবে।
3. **ডিভাইস রিকোয়েস্ট ফাইল খুলুন** → গ্রাহকের পাঠানো `.sauda-device` ফাইল।
4. প্রতিষ্ঠান, মালিক, ফোন, ইমেইল, ঠিকানা, সংস্করণ, মেয়াদ (খালি = লাইফটাইম), সর্বোচ্চ ডিভাইস, ফিচার, নোট দিন।
5. **লাইসেন্স তৈরি করুন** — জেনারেটর প্রথমে নিজেই পাবলিক কী দিয়ে যাচাই করে; ব্যর্থ হলে কিছু দেবে না।
6. **ফাইল সংরক্ষণ (.sauda)** → গ্রাহককে পাঠান; চাইলে লাইসেন্স কী কপিও দিতে পারেন।
7. পুরোনো ফাইল যাচাই করতে **লাইসেন্স যাচাই** বোতাম।

## ৭. থ্রেট মডেল (সৎ মূল্যায়ন)

| হুমকি | প্রতিরোধ |
|---|---|
| লাইসেন্স কী হাতে লেখা/বদল | Ed25519 স্বাক্ষর; পেলোড বদলালেই ব্যর্থ |
| অন্য কম্পিউটারে কপি | হার্ডওয়্যার ফিঙ্গারপ্রিন্ট (৬০% থ্রেশহোল্ড) |
| ঘড়ি পিছিয়ে মেয়াদ বাড়ানো | `license.max_seen` গার্ড |
| ফাঁকা ফিঙ্গারপ্রিন্ট দিয়ে ভিএম | placeholder/অল-জিরো প্রত্যাখ্যান |
| অ্যাপ বাইনারি প্যাচ করে চেক বাদ | সম্ভব — তবে হিসাব ও ডেটা এনক্রিপ্টেড নয় বলে এটি সাধারণ বাণিজ্যিক মান; গুরুত্বপূর্ণ গ্রাহকের জন্য কোড সাইনিং যোগ করা যেতে পারে |
| ডাটাবেজ সরাসরি সম্পাদনা | অডিট লগ + ইন্টিগ্রিটি চেক; তবে অফলাইন অ্যাপে সম্পূর্ণ প্রতিরোধ অসম্ভব |

লাইসেন্সিং **রাজস্ব নিয়ন্ত্রণ** করে, ডেটা সুরক্ষা বা ডেটা এনক্রিপশন করে না।
