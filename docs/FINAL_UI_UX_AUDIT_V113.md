## ২. v1.1.3-এ UI পরিবর্তন

1. **POS সিরিয়াল/IMEI পিকার** — সিরিয়াল-ট্র্যাকড লাইনের পাশে বারকোড বাটন; মডালে সার্চ + তালিকা
   (`serials.available`), নির্বাচিত সিরিয়াল ছোট চিপ হিসেবে দেখায়, পরিমাণ কমালে অতিরিক্ত সিরিয়াল আপনা-আপনি বাদ।
   *কারণ:* আগে সিরিয়াল-পণ্য POS থেকে **বিক্রিই করা যেত না** — এটি নতুন ফিচার নয়, ভাঙা ওয়ার্কফ্লো মেরামত।
2. **ব্যাকআপ টোস্ট** — অটো-ব্যাকআপ ব্যর্থ হলে লাল, সফল হলে নীরব (শুধু ম্যানুয়ালে সবুজ)।
3. **ইমপোর্ট ত্রুটি** — ভুল এক্সটেনশনের ফাইল দিলে স্পষ্ট বাংলা মেসেজ।
