# চূড়ান্ত রিলিজ রিপোর্ট — v1.1.1

তারিখ: ২০২৬-১১-০৪ · শাখা: `arena/73cae273-merqo-retail-suite-app` · ট্যাগ লক্ষ্য: `v1.1.1`

এই রিপোর্টে দুটি পণ্যের **আলাদা রায়** আছে। প্রমাণের স্তর: **L1** স্ট্যাটিক/টাইপ · **L2** স্বয়ংক্রিয় টেস্ট ·
**L3** বিল্ড আর্টিফ্যাক্ট · **L4** ইনস্টলার/রানটাইম · **L5** মানবীয়/ভিজ্যুয়াল। স্যান্ডবক্সে L4–L5 সম্ভব নয়।

## 2. পণ্য-১: সাউদা রিটেইল স্যুট — রায়

**রায়: RELEASE-READY (L1–L3), ইনস্টলার যাচাই সাপেক্ষে (L4)।**

- v1.1.1-এ অ্যাপের ব্যবসায়িক কোড অপরিবর্তিত; স্কিমা v4; **কোনো মাইগ্রেশন নেই**, তাই গ্রাহক ডেটা ও
  বিদ্যমান লাইসেন্স অক্ষত থাকার ঝুঁকি ন্যূনতম।
- অফলাইন-ফার্স্ট শর্ত অটুট: কোনো paid API/SaaS/ক্লাউড/টেলিমেট্রি যুক্ত হয়নি।
- ১৯৯টি কোর টেস্ট অপরিবর্তিত পাস; UI অডিটে কোনো নতুন অসঙ্গতি নেই।

**সীমা যা এখনো দাঁড়িয়ে আছে:** থার্মাল/লেবেল/ড্রয়ার প্রিন্টিং, দ্বিতীয় মনিটর, দুই-PC LAN,
Windows ইনস্টলার/UAC, কোড সাইনিং, লাইভ পাইলট — সবই **BLOCKED (L4–L5)**। এগুলো "পাস" হিসেবে গণ্য করা হয়নি।

কোনো ফাইল/রেকর্ড তৈরি হয় না।

## 4. ইন্টিগ্রেশন: জেনারেটর ⇄ গ্রাহকের অ্যাপ

১০টি ইন্টিগ্রেশন টেস্ট (আসল `@sauda/core` দিয়ে, মক নয়) প্রমাণ করে:

1. জেনারেটরের তৈরি লাইসেন্স অ্যাপ **গ্রহণ করে** (`verifyLicense` activated) — লাইফটাইম, দৈনিক, সব এডিশনে।
2. ফাইল বডি (`toLicenseFile`) অ্যাপের `parseLicenseFile` পড়তে পারে; আসল ডেটাবেজে `activate()` সফল।
3. স্বাক্ষরের পর পেলোড বদলালে **`signature_invalid`**।
4. ভিন্ন পাবলিক কী-তে **প্রত্যাখ্যান**।
5. ভিন্ন মেশিনে **ডিভাইস-মিসম্যাচ**।
6. মেয়াদোত্তীর্ণ লাইসেন্স **`expired`**।
7. প্রত্যাহৃত লাইসেন্সের স্বাক্ষর বৈধ থেকেও জেনারেটরে **প্রত্যাহার-পতাকা** ওঠে।
8. রি-ইস্যুতে পুরোনো `superseded`, নতুনটি বৈধ; স্টোর রাউন্ডট্রিপে অবস্থা অটুট।

এটি **L2+L3** প্রমাণ। "গ্রাহকের আসল Windows মেশিনে ইনস্টল করে দেখেছি" — এটা দাবি করা হচ্ছে না।
