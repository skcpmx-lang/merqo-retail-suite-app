# চূড়ান্ত UI/UX অডিট — v1.1.1 (ফেজ ১৩)

তারিখ: ২০২৬-১১-০৪ · পরিধি: **সাউদা লাইসেন্স জেনারেটর (পুনর্নির্মিত)** এবং রিটেইল অ্যাপের অপরিবর্তিত UI-এর রিগ্রেশন যাচাই।

প্রমাণের স্তর (আগের অডিটের মতোই):
**L1** স্ট্যাটিক/টাইপ · **L2** স্বয়ংক্রিয় টেস্ট · **L3** বিল্ড আর্টিফ্যাক্ট · **L4** ইনস্টলার/রানটাইম ·
**L5** মানবীয় ব্যবহার/ভিজ্যুয়াল। এই স্যান্ডবক্সে **L4 ও L5 সম্ভব নয়** — যেখানে দরকার সেখানে তা স্পষ্ট লেখা আছে।

## ৩. বোতাম ও নেভিগেশন — "ডেড বাটন নেই" কীভাবে যাচাই হলো

`scripts/audit-license-generator.mjs` প্রতিটি `call('রাউট')` সাইট বের করে `main.ts`-এর নিবন্ধিত রাউটের সাথে মেলায়:

- UI → অস্তিত্বহীন রাউট = **fail**;
- নিবন্ধিত কিন্তু UI-তে অপ্রয়োগযোগ্য রাউট = warning (এখন শূন্য);
- preload চ্যানেল ≠ main চ্যানেল = **fail**;
- অস্তিত্বহীন `icon="…"` = **fail**;
- ব্যবহৃত কিন্তু CSS-এ অনুপস্থিত ক্লাস = **fail**;
- `App.tsx`-এ মাউন্ট না হওয়া পাতা = **fail**।

বর্তমান ফল: **১২ পাতা · ৩৭ IPC রাউট · ৪৪ কল সাইট · ১১১ CSS ক্লাস · ২৯ আইকন · ০ সমস্যা**।

এই অডিটের প্রথম চালানিতেই একটি **প্রকৃত ত্রুটি** ধরা পড়ে — `Generate.tsx`-এ ব্যবহৃত `.step-label` ক্লাস
CSS-এ ছিল না (উইজার্ডের ধাপের নাম বিনা-স্টাইলে দেখাত)। ঠিক করা হয়েছে এবং II ধাপে `.step-label` স্টাইল যোগ হয়েছে।
দ্বিতীয় প্রকৃত ত্রুটি: `revokedIds()` পুরোনো লেজার লাইন দেখে নতুন প্রত্যাহার বাতিল করে দিত — ঠিক করা হয়েছে
ও টেস্টে আটকানো হয়েছে।

## ৫. কনসিস্টেন্সি ও ফিনিশ

- সব সংখ্যা বাংলা অংকে (নতুন `bnNum()` হেল্পার — "ধাপ ২", "ধাপ ৯")। (L1+L2)
- লোডিং, খালি অবস্থা ও ত্রুটি — প্রতিটি পাতায়; ত্রুটি টোস্টেই বাংলা বার্তা। (L2: SSR পেইন্ট)
- কোনো স্পিনার চিরকাল ঘুরে থাকে না — প্রতিটি `loading` স্টেট `finally`-তে ছাড়া হয়। (L1 পর্যালোচনা)
- লাইট ও ডার্ক — একই টোকেন সেট, `data-theme` অ্যাট্রিবিউট; সেটিংসে সংরক্ষিত। (L1+L2)
- রঙের অর্থ স্থির: সবুজ=সক্রিয়, অ্যাম্বার=শীঘ্রই মেয়াদ, লাল=প্রত্যাহার/ত্রুটি, নীল=তথ্য।

## ৬. রিটেইল অ্যাপের রিগ্রেশন (অপরিবর্তিত UI)

v1.1.1-এ রিটেইল অ্যাপের UI কোড **পরিবর্তিত হয়নি** — শুধু সংস্করণ নম্বর। তবু গেট চালানো হয়েছে:

- টাইপচেক ৩ প্যাকেজ — ০ ত্রুটি;
- ২২৯ টেস্ট (২১ ফাইল) — সব পাস, যার মধ্যে ১৯৯টি আগের + ৩০টি জেনারেটরের নতুন;
- `audit-ui.mjs` — ৩৫ ফাইল · ৪৮ আইকন · ২৪০ CSS ক্লাস · ২৪২ IPC রাউট · ১৮৪ কল সাইট, অসঙ্গতি নেই।
