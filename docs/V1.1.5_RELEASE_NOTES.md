## Installation

1. Run `Sauda-Retail-Suite-Setup-1.1.5.exe` on the **Main PC**.
2. Complete Setup (business details, admin user).
3. Activate the shop licence (Settings → Licence) using the file issued by
   `Sauda-License-Generator-1.1.5.exe`.
4. For Client PCs: Settings → Network → enable Server Mode, and allow the Windows firewall prompt for
   **Private** networks only.
5. On each Client PC: install the same file, choose **Client PC**, enter the Main PC's address or scan
   the pairing QR, then approve the pending device on the Main PC (Settings → Devices).

## Upgrading from v1.1.4

1. **Back up first** on the Main PC (Shop → Backup) and copy the file off the machine. Note the
   counts: products / sales / customers / total dues.
2. Close the app on every PC.
3. Install v1.1.5 on the Main PC and start it. The existing database is upgraded in place; a
   pre-upgrade copy is written automatically.
4. Confirm the counts match, then open a sale, a purchase and a report.
5. Client PCs: install v1.1.5 and reconnect. Licences issued for v1.1.4 remain valid.
6. Keep the v1.1.4 installer and the backup until you are satisfied.

## Backup

- Main PC: Shop → Backup (manual) and Settings → Backup schedule (automatic), written under
  `%APPDATA%\Sauda Retail Suite\backups`.
- A Client PC refuses backup/restore by design.
- Copy backups off the Main PC regularly — same-disk backups do not survive a disk failure.

## Rollback (v1.1.5 → v1.1.4)

1. Quit the app on all PCs (tray → Quit) to release the database lock.
2. Uninstall v1.1.5 (the data directory is preserved).
3. Reinstall v1.1.4.
4. If the database was upgraded, replace `%APPDATA%\Sauda Retail Suite\data\sauda.db` with the
   pre-upgrade backup and delete the `-wal` / `-shm` sidecars left by v1.1.5.
5. Reinstall v1.1.4 on each Client PC.

## Verify your download

```bat
certutil -hashfile Sauda-Retail-Suite-Setup-1.1.5.exe SHA256
certutil -hashfile Sauda-License-Generator-1.1.5.exe SHA256
```

Compare both hashes with `SHA256SUMS.txt` on this release page before running the installer. These
builds are **unsigned** — Windows will report an "Unknown publisher" and may show "Windows protected
your PC" on first run: choose "More info" → "Run anyway" only after the hashes match. A mismatch
means the download is corrupt or tampered with; delete it.

## Known limitations

- Client PCs require a working network link to the Main PC; there is no offline trading mode by design.
- **Revocation is offline.** Revoking a licence in the License Generator stops it being exported again
  and marks the record, but a PC that is already activated keeps running until the licence's expiry
  date — the Main App does not contact a server to check.
- Device count is bounded by the licence; no throughput figures are published because none were
  measured on customer hardware.
- The installers are unsigned, so Windows shows “Unknown publisher” / SmartScreen on first run.
- Licence-signing key rotation is a manual, documented procedure.
